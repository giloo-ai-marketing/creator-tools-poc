# Giloo Creator Tools POC

產品介面 POC，給工程和行銷對齊用。沒有後端，所有流程都在瀏覽器模擬。

- 左側固定側欄：New chat、Projects、Skills、Connectors、Chats
- 頂部 Nav：五個產品，字幕翻譯、官網 Press Kit、行銷策略報告、社群後台、輿情分析
- 中間對話框，下面 20 個導演情境
- 每個產品的第一輪是收件卡，按開始後跑流程，結果出現在右側面板
- 兩個完整二級頁面：`workspace.html` 示範行銷策略報告，`festival-kit.html` 示範英文影展文案與字幕的複合送件包

畫面裡的片名、數字、名單都是範例。
